# Global Widget

Manage reusable global widgets and their editor dialogs.

Components render the interface; hooks coordinate state; services and persistence adapters perform I/O; types describe contracts. Follow the files that exist here rather than adding empty layers.

| File | Responsibility |
| --- | --- |
| [components/GlobalWidgetLibrary.tsx](components/GlobalWidgetLibrary.tsx) | Global widget feature: Global Widget Library. Keep feature UI, hooks, services and types in this module. |
| [components/SaveGlobalWidgetDialog.tsx](components/SaveGlobalWidgetDialog.tsx) | Global widget feature: Save Global Widget Dialog. Keep feature UI, hooks, services and types in this module. |
| [hooks/useGlobalWidgets.ts](hooks/useGlobalWidgets.ts) | Global widget feature: use Global Widgets. Keep feature UI, hooks, services and types in this module. |
| [index.ts](index.ts) | Global widget feature: index. Keep feature UI, hooks, services and types in this module. |
| [services/globalWidgetService.ts](services/globalWidgetService.ts) | Global widget feature: global Widget Service. Keep feature UI, hooks, services and types in this module. |
| [types/globalWidget.types.ts](types/globalWidget.types.ts) | Global widget feature: global Widget types. Keep feature UI, hooks, services and types in this module. |
